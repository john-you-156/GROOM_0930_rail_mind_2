# 마음역 전문가 콘텐츠 검수 패킷

- 검수 대상 버전: 콘텐츠 v0.1
- 상태: 검수 대기
- 검수자: 미기재
- 검수 완료일: 미기재
- 다음 재검토 시점: 기능 또는 질문 콘텐츠 변경 시

## 1. 검수 목적

마음역의 규칙 기반 질문, 작은 행동, 음악 확장 방향, 위기 안내와 장애 접근성이 사용자에게 불필요한 압박이나 오해를 주지 않는지 음악치료 및 장애인복지 현장 관점에서 확인한다.

이 검수는 임상시험, 의료기기 인허가 또는 치료 효과 검증을 의미하지 않는다.

## 2. 검수자의 앱 내 역할 후보

실제 참여 범위에 맞는 항목 하나를 합의 후 사용한다.

- [ ] 음악치료 콘텐츠 자문
- [ ] 감정 질문 및 음악 콘텐츠 전문 검수
- [ ] 음악 기반 정서 조절 콘텐츠 공동 설계
- [ ] 접근성 및 장애인복지 관점 검수

`이화여자대학교 인증`, `임상적으로 검증`, `치료 효과 보장` 등의 표현은 별도 근거와 공식 승인이 없으면 사용하지 않는다.

## 3. 기본 정보 확인

- [ ] 공개할 성명과 사진에 본인이 동의했다.
- [ ] 학교·대학원·전공·학위 명칭이 학위증과 일치한다.
- [ ] 음악치료 관련 자격명, 발급기관, 자격 종류를 정확히 확인했다.
- [ ] 장애인복지 실무경력의 기간과 업무 범위를 확인했다.
- [ ] 학교 로고나 기관 로고를 무단 사용하지 않는다.
- [ ] 앱에서 공개할 담당 범위를 서면으로 합의했다.

## 4. 질문 콘텐츠 검수

검수 원문: `docs/CONVERSATION_CONTENT.md`

각 감정별 질문을 다음 기준으로 검토한다.

- [ ] 질문이 감정을 진단하거나 단정하지 않는다.
- [ ] 사용자가 특정 답변을 하도록 유도하지 않는다.
- [ ] 긍정적으로 생각하라고 강요하지 않는다.
- [ ] 비난이나 죄책감을 유발할 표현이 없다.
- [ ] 추상적이거나 이해하기 어려운 표현이 과도하지 않다.
- [ ] 한 화면에 질문 하나라는 원칙에 적합하다.
- [ ] 답변하지 않고 건너뛸 수 있어야 하는 질문을 구분했다.
- [ ] 작은 행동이 처방이나 치료 지시처럼 보이지 않는다.
- [ ] 위기 상황에서 일반 질문을 계속하지 않는다.

## 5. 위기 안내 검수

- [ ] 앱이 전문 상담이나 치료의 대체재가 아님을 분명히 한다.
- [ ] 자해·자살·타해 가능 표현에서 일반 흐름을 중단한다.
- [ ] 112, 119, 109, 1577-0199 안내의 표현과 우선순위가 적절하다.
- [ ] 키워드 기반 감지의 한계를 사용자에게 숨기지 않는다.
- [ ] 도움 화면이 공포나 죄책감을 불필요하게 높이지 않는다.
- [ ] 사용자가 도움 화면을 언제든 직접 열 수 있다.

## 6. 장애 접근성 검수

- [ ] 쉬운 문장과 예측 가능한 순서를 사용한다.
- [ ] 색상 외에도 선택 상태를 표시한다.
