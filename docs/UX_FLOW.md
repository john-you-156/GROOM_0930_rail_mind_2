# 마음역 화면 및 사용자 흐름 명세

- 문서 버전: 1.0
- 기준 PRD: `docs/PRD.md` v1.1
- 대상: GPT API 없는 규칙 기반 MVP

## 1. 정보 구조

```text
홈
├─ 마음 여행 시작
│  ├─ 안전 안내
│  ├─ 감정 선택
│  ├─ 사진 선택
│  ├─ 단계별 성찰
│  ├─ 작은 행동 선택
│  └─ 결과
│     ├─ 비공개 저장
│     └─ 공유 카드 제작
├─ 나의 기록
│  └─ 기록 상세·삭제
├─ 도움받기
└─ 설정
   ├─ 자동 저장
   ├─ 안내 음성
   └─ 전체 기록 삭제
```

## 2. 전체 사용자 흐름

```text
[홈]
  │
  ├─ 시작하기
  ▼
[안전 안내 및 저장 선택]
  │
  ▼
[감정 선택]
  │ 감정 0~3개, 강도 선택사항
  ▼
[사진 선택]
  │ 추천 사진 6장 또는 직접 검색
  ▼
[성찰 1: 사진을 고른 이유]
  │ 텍스트 / 음성
  ▼
[성찰 2: 가장 크게 느껴지는 것]
  │ 자유 답변 또는 선택형 건너뛰기
  ▼
[성찰 3: 지금 필요한 것]
  │ 감정별 선택지
  ▼
[작은 행동 선택]
  │ 미리 정의된 행동 또는 직접 입력
  ▼
[비공개 결과]
  ├─ 저장하지 않고 종료
  ├─ 로컬 저장
  └─ 공유 카드 만들기
       ▼
     [카드 편집]
       ▼
     [이미지 저장 / 공유 / 문구 복사]
```

## 3. 화면별 와이어프레임

### 3.1 홈

```text
┌────────────────────────────┐
│ 마음역                     │
│                            │
│ 지금 마음은                │
│ 어느 역에 머물러 있나요?   │
│                            │
│  [ 마음 여행 시작하기 ]    │
│                            │
│ [나의 기록]   [도움받기]   │
│                            │
│ 진단·치료 서비스가 아닙니다 │
└────────────────────────────┘
```

### 3.2 감정 선택

```text
┌────────────────────────────┐
│ 1 / 5                      │
│ 지금 마음에 가까운 단어는? │
│ 최대 3개까지 골라주세요.   │
│                            │
│ [평온] [기쁨] [설렘]       │
│ [피곤] [답답] [불안]       │
│ [외로움] [화남] [모르겠음] │
│                            │
│          [ 다음 ]          │
└────────────────────────────┘
```

### 3.3 사진 선택

```text
┌────────────────────────────┐
│ 2 / 5                      │
│ 지금 마음과 닮은 장면은?   │
│ [검색어________________] 🔍 │
│                            │
│ [사진] [사진]              │
│ [사진] [사진]              │
│ [사진] [사진]              │
│                            │
│ [다른 사진 보기] [다음]    │
└────────────────────────────┘
```

사진 하단에는 사진가 이름과 Unsplash 링크를 표시한다.

### 3.4 단계별 성찰

```text
┌────────────────────────────┐
│ 3 / 5        [도움이 필요해요]│
│                            │
│ [선택한 사진 흐린 배경]    │
│                            │
│ 이 장면의 어떤 부분이       │
│ 지금 마음과 닮았나요?      │
│                            │
│ ┌────────────────────────┐ │
│ │ 답변을 입력하세요       │ │
│ └────────────────────────┘ │
│ [텍스트] [🎙 누르고 말하기]│
│                            │
│ [건너뛰기]       [다음]    │
└────────────────────────────┘
```

음성 인식 후에는 곧바로 전송하지 않는다. 변환된 문장을 입력창에 넣어 사용자가 수정한 뒤 `다음`을 누르게 한다.

### 3.5 비공개 결과

```text
┌────────────────────────────┐
│ 오늘의 마음역              │
│                            │
│          안개역            │
│ [선택한 사진]              │
│                            │
│ 오늘 발견한 문장           │
│ “모든 것을 오늘 결정할     │
│ 필요는 없다.”              │
│                            │
│ 다음 정거장                │
│ 내일 할 일 하나만 적기     │
│                            │
│ [나만의 기록으로 저장]     │
│ [공유용 마음 카드 만들기]  │
│ [저장하지 않고 마치기]     │
└────────────────────────────┘
```

### 3.6 공유 카드 편집

```text
┌────────────────────────────┐
│ 공유 카드 만들기           │
│ [카드 미리보기]            │
│                            │
│ 공개 문장 [____________]   │
│ 비율 [세로][정사각][가로]  │
│ 필터 [밝기][블러][흑백]    │
│ 정렬 [왼쪽][가운데]        │
│                            │
│ □ 개인정보를 확인했습니다  │
│ [이미지 저장] [공유하기]   │
│ [문구 복사]                │
└────────────────────────────┘
```

## 4. 입력 방식 전환

### 텍스트

- 항상 사용할 수 있는 기본 입력 방식이다.
- 질문마다 최대 500자로 제한한다.
- 빈 답변은 `건너뛰기`로 처리한다.

### 음성

- 사용자가 마이크 버튼을 누를 때만 인식을 시작한다.
- 첫 사용 시 브라우저 권한을 요청한다.
- 인식 중임을 색상, 문구, 간단한 파형으로 표시한다.
- `말하기 종료`를 누르면 결과를 텍스트 입력창에 넣는다.
- 사용자는 변환 결과를 수정하거나 삭제할 수 있다.
- 미지원·권한 거부·오류 시 텍스트 모드로 돌아간다.
- 음성 원본 파일은 저장하지 않는다.

## 5. 규칙 기반 분기 흐름

```text
선택 감정
  ├─ 불안·답답함 → 통제 가능한 것과 필요한 안정 질문
  ├─ 피곤함      → 에너지와 휴식 필요 질문
  ├─ 외로움      → 연결감과 연락 가능한 사람 질문
  ├─ 화남        → 사건·몸의 반응·안전한 거리두기 질문
  ├─ 기쁨·설렘   → 의미와 간직하고 싶은 점 질문
  ├─ 평온함      → 평온을 만든 조건과 유지 질문
  └─ 모르겠음    → 몸의 감각·날씨 비유 질문
```

사용자 자유 답변의 내용을 분석해 분기하지 않는다. 사용자가 처음 선택한 감정과 화면에서 고른 선택지만 다음 질문 결정에 사용한다.

## 6. 예외 흐름

### Unsplash 오류

- 다시 시도 버튼을 표시한다.
- 번들에 포함된 샘플 사진 또는 색상 그라데이션 카드를 보여준다.
- 이미 선택한 감정과 답변은 유지한다.

### 음성 기능 오류

- 오류 원인을 간단하게 안내한다.
- 입력 내용을 잃지 않고 텍스트 모드로 전환한다.

### 위기 표현 감지

- `다음` 진행을 멈추고 도움 화면을 먼저 보여준다.
- 사용자가 원하면 현재 답변을 수정하고 일반 흐름으로 돌아갈 수 있다.
- 키워드 감지가 정확한 위험 판정이 아님을 명시한다.

### 공유 미지원

- 이미지 파일 다운로드와 문구 복사 버튼을 제공한다.

## 7. 접근성 요구

- 색상만으로 선택 상태를 표현하지 않는다.
- 모든 사진에 대체 텍스트를 제공한다.
- 마이크 상태를 텍스트로 함께 표시한다.
- 모든 주요 기능을 키보드로 사용할 수 있게 한다.
- 움직임 감소 설정을 존중한다.
- 카드 텍스트와 배경의 대비를 자동 오버레이로 보장한다.
