# 마음역 MVP 기능명세서

- 문서 버전: 1.0
- 우선순위: P0 필수, P1 권장, P2 이후

## 1. 세션과 진행 상태

| ID | 기능 | 우선순위 | 완료 조건 |
|---|---|---:|---|
| SES-01 | 새 마음 세션 시작 | P0 | 홈에서 빈 세션이 만들어진다. |
| SES-02 | 단계 이동 | P0 | 이전·다음 이동 시 입력값이 유지된다. |
| SES-03 | 세션 취소 | P0 | 확인 후 임시 데이터가 삭제된다. |
| SES-04 | 새로고침 복구 | P1 | 진행 중 세션을 이어갈 수 있다. |

## 2. 감정과 사진

| ID | 기능 | 우선순위 | 완료 조건 |
|---|---|---:|---|
| EMO-01 | 감정 선택 | P0 | 0~3개 감정을 선택·해제할 수 있다. |
| EMO-02 | 감정 강도 | P1 | 1~5 중 하나를 선택하거나 생략한다. |
| IMG-01 | 추천 사진 조회 | P0 | 감정 매핑 검색어로 사진 6장을 표시한다. |
| IMG-02 | 사진 검색 | P0 | 사용자가 직접 검색어를 입력할 수 있다. |
| IMG-03 | 사진 선택 | P0 | 사진 ID·URL·사진가·링크를 세션에 저장한다. |
| IMG-04 | 출처 표시 | P0 | 사진가와 Unsplash 링크가 사진 주변에 표시된다. |
| IMG-05 | 오류 대체 | P0 | API 실패 시 샘플 이미지 또는 그라데이션을 표시한다. |

## 3. 성찰 질문

| ID | 기능 | 우선순위 | 완료 조건 |
|---|---|---:|---|

## 4. 음성

| ID | 기능 | 우선순위 | 완료 조건 |
|---|---|---:|---|
| VOC-01 | 마이크 지원 확인 | P0 | 미지원 환경에서 음성 버튼 대신 안내를 표시한다. |

## 8. 설정과 오류

| ID | 기능 | 우선순위 | 완료 조건 |
