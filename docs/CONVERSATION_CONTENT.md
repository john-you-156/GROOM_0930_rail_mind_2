# 마음역 규칙 기반 대화 콘텐츠 명세

- 문서 버전: 1.0
- 목적: GPT 없이도 일관된 3~7분 자기성찰 흐름 제공

## 1. 대화 구조

모든 세션은 다섯 단계로 구성한다.

1. 감정 선택
2. 사진 선택과 이유
3. 감정별 질문
4. 지금 필요한 것 선택
5. 작은 행동과 결과 문장 선택

자유 답변은 저장과 결과 카드 후보 문장에만 사용한다. 자연어 분석이나 심리 추론에는 사용하지 않는다.

## 2. 공통 질문

| 단계 | 질문 | 건너뛰기 |
|---|---|---|
| 사진 이유 | 이 장면의 어떤 부분이 지금 마음과 닮았나요? | 가능 |
| 현재 초점 | 지금 가장 마음에 걸리는 것은 무엇인가요? | 가능 |
| 필요 확인 | 지금의 나에게 가장 필요한 것은 무엇인가요? | 선택 필수 |
| 작은 행동 | 오늘 할 수 있는 가장 작은 행동은 무엇일까요? | 선택 필수 |

## 3. 감정별 질문 템플릿

### 불안함

- 아직 일어나지 않았지만 걱정되는 일이 있나요?
- 그중 지금 확인할 수 있는 것과 기다려야 하는 것은 무엇인가요?
- 지금 몸을 조금 편안하게 만드는 데 필요한 것은 무엇인가요?

필요 선택지: 확실한 정보, 잠깐의 휴식, 계획 한 가지, 누군가의 도움, 그냥 들어주는 시간

### 답답함

- 무엇이 막혀 있다고 느껴지나요?
- 지금 바꿀 수 있는 부분과 당장 바꾸기 어려운 부분을 나눠볼까요?
- 잠시 내려놓아도 되는 것은 무엇인가요?

필요 선택지: 정리, 거리두기, 표현, 도움 요청, 휴식

### 피곤함

- 몸의 피로와 마음의 피로 중 어느 쪽이 더 크게 느껴지나요?
- 오늘 이미 충분히 해낸 것은 무엇인가요?
- 지금 줄여도 되는 일은 무엇인가요?

필요 선택지: 수면, 조용한 시간, 식사·물, 일정 줄이기, 위로

### 외로움

- 혼자 있다는 느낌과 이해받지 못한다는 느낌 중 어느 쪽에 가까운가요?
- 부담 없이 연락할 수 있는 사람이 떠오르나요?
- 지금 원하는 연결은 대화, 함께 있기, 또는 조용한 관심 중 무엇인가요?

필요 선택지: 연락, 동행, 공감, 혼자 쉴 공간, 전문적인 도움

### 화남

- 어떤 일이 내 기준이나 경계를 건드렸나요?
- 지금 몸에서는 화가 어떻게 느껴지나요?
- 바로 반응하기 전에 필요한 거리는 어느 정도일까요?

필요 선택지: 거리두기, 감정 표현, 경계 세우기, 사실 정리, 진정할 시간

### 기쁨·설렘

- 이 마음을 만들어 준 순간은 무엇인가요?
- 누구와 나누거나 어떻게 기억하고 싶나요?
- 이 기분에서 내가 중요하게 여기는 것은 무엇인가요?

필요 선택지: 기록, 공유, 감사, 도전, 충분히 즐기기

### 평온함

- 오늘의 평온을 만들어 준 것은 무엇인가요?
- 이 상태를 지키기 위해 덜어낼 것은 무엇인가요?
- 내일도 이어가고 싶은 작은 조건은 무엇인가요?

필요 선택지: 유지, 휴식, 정리, 감사, 천천히 하기

### 잘 모르겠음

- 지금 몸에서 가장 먼저 느껴지는 감각은 무엇인가요?
- 지금 마음을 날씨로 표현한다면 어떤가요?
- 좋고 나쁨을 정하지 않고 가장 눈에 띄는 생각을 적어볼까요?

필요 선택지: 이름 붙일 시간, 휴식, 대화, 움직임, 그냥 머물기

## 4. 작은 행동 목록

각 행동은 사용자가 직접 선택하며 앱이 자동 처방하지 않는다.

| ID | 표시 문구 | 관련 필요 |
|---|---|---|
| drink_water | 물 한 잔 천천히 마시기 | 휴식, 몸 돌보기 |
| breathe_3m | 3분 동안 천천히 호흡하기 | 안정, 거리두기 |
| walk_5m | 5분 동안 주변 걷기 | 움직임, 환기 |
| write_one | 내일 할 일 하나만 적기 | 정리, 계획 |
| contact_one | 믿을 수 있는 사람 한 명에게 연락하기 | 연결, 도움 요청 |
| pause_decision | 중요한 결정은 오늘 잠시 미루기 | 거리두기, 안정 |
| reduce_one | 오늘 할 일 하나 덜어내기 | 휴식, 일정 줄이기 |
| gratitude_one | 고마웠던 순간 하나 기록하기 | 감사, 유지 |
| custom | 직접 입력하기 | 전체 |

## 5. 마음역 이름 규칙

마음역 이름은 감정과 필요 선택의 조합으로 결정한다. 사용자 자유 답변을 분석하지 않는다.

| 감정 | 기본 역 이름 후보 |
|---|---|
| 불안함 | 안개역, 기다림역, 숨고르기역 |
| 답답함 | 갈림길역, 잠시멈춤역, 틈새역 |
| 피곤함 | 쉼표역, 느린역, 오늘도착역 |
| 외로움 | 연결역, 온기역, 곁역 |
| 화남 | 거리두기역, 경계역, 식힘역 |
| 기쁨 | 햇살역, 반짝임역, 간직역 |
| 설렘 | 출발역, 두근역, 새길역 |
| 평온함 | 고요역, 머무름역, 잔잔역 |
| 잘 모르겠음 | 이름없는역, 흐린역, 천천히역 |

같은 감정 안에서는 사진의 `orientation` 또는 사용자가 선택한 필요 ID를 이용해 후보를 결정하되, 심리적 의미를 부여하지 않는다.

## 6. 결과 문장 생성 규칙

결과 문장은 생성형 AI 대신 템플릿을 이용한다.

```text
오늘 나는 {감정표현} 마음을 알아차렸습니다.
지금 필요한 것은 {필요표현}입니다.
다음 정거장에서는 {작은행동표현}을 해보겠습니다.
```

공유 카드 기본 문장은 더 짧게 제공한다.

```text
오늘의 마음역은 {역이름}.
지금 나에게 필요한 것은 {필요표현}입니다.
```

사용자는 결과 문장을 자유롭게 수정할 수 있다.

## 7. 안전 키워드 처리

위기 가능성이 있는 표현은 별도의 로컬 키워드 목록으로 검사한다. 목록은 소스코드와 분리된 설정 파일에서 관리한다.

처리 원칙:

1. 일치 시 진단하거나 위험도를 점수화하지 않는다.
2. 일반 흐름을 잠시 중단하고 도움 화면을 우선 표시한다.
3. 즉각적인 위험이면 112·119, 자살 관련 위기면 109, 정신건강 상담은 1577-0199를 안내한다.
4. 사용자가 현재 안전하다고 확인하더라도 전문적인 도움이 필요하면 사람과 연결하도록 안내한다.
5. 공개 출시 전에 전문가가 키워드와 안내 문구를 검토해야 한다.

개발용 테스트 문자열은 실제 사용자 콘텐츠와 섞이지 않게 별도 테스트 픽스처에 둔다.

## 8. 콘텐츠 작성 원칙

- 질문은 한 화면에 하나만 보여준다.
- 답을 유도하거나 평가하지 않는다.
- `왜 그랬나요?`보다 구체적이고 비난하지 않는 표현을 사용한다.
- 긍정적으로 생각하라고 강요하지 않는다.
- 감정을 없애야 할 문제로 표현하지 않는다.
- 질문은 최대 45자, 안내 문구는 최대 80자를 목표로 한다.
- 전문가 검토 전에는 임상 용어나 치료 기법 명칭을 마케팅에 사용하지 않는다.
