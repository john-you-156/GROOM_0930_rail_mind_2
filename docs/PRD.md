# 마음역 MVP 제품 기획서

- 문서 상태: Approved for specification v1.1
- 작성일: 2026-09-30
- 제품 형태: 모바일 우선 반응형 웹앱
- 기술 방향: React, Vite, localStorage, Unsplash API

## 1. 제품 한 문장

마음역은 사용자가 자신의 마음과 닮은 사진을 고른 뒤 텍스트 또는 음성으로 정해진 성찰 질문에 답하며 감정을 정리하고, 공개하고 싶은 문장만 사진 카드로 만들어 저장하거나 공유하는 자기성찰 웹앱이다.

## 2. 제품 포지셔닝

마음역은 의료 서비스, 심리 진단 도구 또는 전문 상담의 대체재가 아니다. 일상적인 감정 표현과 자기성찰을 돕는 웰니스 도구다.

제품 안에서는 다음 표현을 사용한다.

- 마음 대화
- 감정 정리
- 자기성찰
- 오늘의 작은 행동
- 도움이 필요할 때 연결할 수 있는 전문기관

다음 표현은 사용하지 않는다.

- AI 심리치료사
- 우울증·불안장애 진단
- 치료 효과 보장
- 상담사를 대체한다는 표현

## 3. 해결하려는 문제

사용자는 마음이 복잡할 때 다음과 같은 어려움을 겪는다.

1. 현재 감정을 말로 시작하기 어렵다.
2. 누군가에게 바로 털어놓기는 부담스럽다.
3. 일반적인 챗봇의 빈 입력창은 대화 시작 장벽이 높다.
4. 기록을 남기고 싶지만 긴 일기를 쓰기는 어렵다.
5. 자기성찰 결과 중 일부만 시각적으로 간직하거나 공유하고 싶다.

마음역은 사진을 감정 표현의 출발점으로 사용하고, 한 번에 하나의 짧은 질문을 제시해 이 장벽을 낮춘다.

## 4. 목표 사용자

### 핵심 사용자

- 일상적인 스트레스와 감정을 정리하고 싶은 성인
- 긴 글보다 사진이나 대화로 마음을 표현하기 쉬운 사람
- 출퇴근 또는 잠들기 전 3~7분 동안 짧게 돌아보고 싶은 사람
- 상담이나 진단보다 부담 없는 자기성찰 경험을 원하는 사람

### 초기 사용 상황

- 퇴근길에 오늘 있었던 일을 정리할 때
- 중요한 결정을 앞두고 생각이 복잡할 때
- 누군가와 갈등한 뒤 감정을 먼저 가라앉히고 싶을 때
- 하루를 마치며 한 문장으로 기록하고 싶을 때

## 5. 핵심 가치

### 말하기 전에도 표현할 수 있다

사진을 고르는 행위 자체가 대화의 시작점이 된다.

### 사용자가 대화 방식을 통제한다

텍스트와 음성을 언제든 전환할 수 있고, 음성은 전송 전에 변환된 문장을 확인하고 수정할 수 있다.

### 기록과 공개를 분리한다

전체 대화는 비공개이며, 사용자가 직접 선택한 문장만 공유 카드에 포함된다.

### 작은 다음 행동으로 마친다

대화는 거창한 해결책 대신 사용자가 직접 선택한 현실적인 한 걸음으로 끝난다.

## 6. MVP 핵심 사용자 흐름

```text
시작 및 안전 안내
  → 현재 감정 선택
  → 마음과 닮은 Unsplash 사진 선택
  → 사진을 고른 이유 입력
  → 텍스트 또는 음성으로 단계별 질문에 답변
  → 오늘의 작은 행동 선택
  → 비공개 성찰 결과 확인
  → 로컬 저장 또는 기록하지 않기
  → 선택적으로 공유용 마음 카드 제작
  → 이미지 저장·문구 복사·기본 공유 메뉴 호출
```

## 7. 주요 화면

### 7.1 시작 화면

목적은 서비스의 성격과 한계를 짧고 분명하게 알리는 것이다.

- 서비스 소개
- `마음 여행 시작하기` 버튼
- 치료·진단 서비스가 아니라는 안내
- 기록 저장 여부 기본 설정
- 개인정보 및 위기 도움 안내 링크

### 7.2 감정 선택 화면

- 감정 예시: 평온함, 기쁨, 설렘, 피곤함, 답답함, 불안함, 외로움, 화남, 잘 모르겠음
- 최대 3개까지 선택
- 감정 강도 1~5 선택은 선택사항
- 감정을 고르지 않고 다음 단계로 이동 가능

### 7.3 사진 선택 화면

- 감정 또는 사용자가 입력한 키워드에 따라 사진 6장 표시
- 사진 새로고침
- 직접 검색
- 사진가 이름과 Unsplash 링크 표시
- 사진을 심리검사처럼 해석하지 않는다는 짧은 안내

### 7.4 대화 화면

- 선택 사진을 흐린 배경으로 표시
- 안내 질문과 사용자 답변을 구분
- 입력 방식 전환: `텍스트` / `음성`
- 음성은 Push-to-Talk 방식
- 음성 인식 결과를 전송 전에 확인·수정
- 다음 안내 질문을 텍스트로 표시
- 안내 질문 음성 재생·정지
- 음성 자동 재생 기본값은 꺼짐
- `대화 종료`와 `도움이 필요해요` 버튼 상시 제공

### 7.5 작은 행동 선택 화면

앱은 미리 작성된 낮은 위험의 선택지를 제시하고 사용자가 직접 고른다.

- 물 한 잔 마시기
- 3분간 천천히 호흡하기
- 잠시 걷기
- 내일 할 일 하나만 적기
- 믿을 수 있는 사람에게 연락하기
- 오늘은 결정을 미루기
- 직접 입력하기

### 7.6 비공개 결과 화면

- 오늘의 마음역 이름
- 사용자가 선택한 감정
- 사용자가 직접 선택하거나 수정한 핵심 문장
- 오늘의 작은 행동
- 선택한 사진
- `나만의 기록으로 저장`
- `저장하지 않고 마치기`
- `공유용 마음 카드 만들기`

### 7.7 공유 카드 편집 화면

- 공개할 문장은 기본적으로 비어 있음
- 사용자가 대화에서 문장을 선택하거나 직접 작성
- 사진 교체
- 밝기, 오버레이, 블러, 흑백 조절
- 텍스트 위치, 크기, 정렬 변경
- 세로형, 스토리형, 가로형, 정사각형 비율 제공
- 사진가 크레딧 표시
- 개인정보 확인 체크
- 최종 미리보기

### 7.8 기록 화면

- 날짜별 마음 기록
- 사진과 마음역 이름 중심의 카드 목록
- 개별 삭제
- 전체 기록 삭제
- 기록 내보내기는 MVP 이후 검토

### 7.9 도움 화면

- 앱이 제공할 수 있는 도움의 범위
- 전문적인 도움이 필요한 상황 안내
- 자살예방상담전화 109
- 정신건강상담전화 1577-0199
- 즉각적인 위험 상황의 112·119 안내

## 8. 규칙 기반 성찰 대화 원칙

MVP는 GPT 또는 다른 생성형 AI API를 사용하지 않는다. 감정별로 검토된 질문 템플릿과 선택 규칙을 이용해 다음 질문을 결정한다.

### 해야 하는 것

- 사용자의 말을 짧게 반영하고 요약한다.
- 감정을 단정하지 않고 확인한다.
- 한 번에 질문 하나만 한다.
- 해결책을 제시하기 전에 사용자가 더 이야기할지 묻는다.
- 사용자가 스스로 의미와 다음 행동을 선택하도록 돕는다.
- 대화를 3~7분 안에 마칠 수 있게 한다.
- 모호하거나 잘못 이해했을 가능성을 인정한다.

### 하지 말아야 하는 것

- 정신질환이나 성격을 진단하지 않는다.
- 사진 선택만으로 심리 상태를 추론하지 않는다.
- 약물이나 전문 치료의 시작·중단을 권하지 않는다.
- 사용자의 가족·동료 등 제삼자를 진단하지 않는다.
- 앱에게만 의존하도록 유도하지 않는다.
- 지나치게 친밀하거나 배타적인 관계를 암시하지 않는다.
- 위기 신호가 있는 대화를 일반적인 위로로 계속하지 않는다.

### 기본 말투

- 따뜻하지만 과도하게 감상적이지 않음
- 존댓말
- 짧고 명확한 문장
- 사용자의 표현을 존중하되 그대로 과장하지 않음
- `그랬군요`의 반복보다 구체적인 반영 사용

## 9. 위기 대응 원칙

사용자가 자해, 자살, 타해 또는 즉각적인 위험을 나타내면 일반 성찰 대화를 중단한다.

위기 화면은 다음을 제공한다.

1. 지금 혼자 감당하지 않아도 된다는 짧은 문장
2. 즉각적인 위험 여부 확인
3. 위험하면 112 또는 119에 연락하도록 안내
4. 24시간 자살예방상담전화 109 안내
5. 24시간 정신건강상담전화 1577-0199 안내
6. 가까운 신뢰할 수 있는 사람에게 연락하도록 제안

키워드 감지는 보조 안전장치일 뿐 정확한 위험 판정 기능으로 홍보하지 않는다. 실제 공개 서비스 전에는 정신건강 전문가가 대화 정책과 위기 흐름을 검토해야 한다.

## 10. 공유와 프라이버시 원칙

- 전체 대화 원문은 공유 카드에 자동 삽입하지 않는다.
- 공개할 문장은 사용자가 직접 선택하고 수정한다.
- 앱이 조합한 공개용 문장은 사용자의 승인 없이는 사용하지 않는다.
- 이름, 연락처, 직장, 구체적 장소 등 개인정보 포함 가능성을 게시 전에 알린다.
- 감정명과 `심리 상담` 등의 해시태그를 자동 생성하지 않는다.
- 한 번의 클릭으로 특정 SNS에 자동 게시하지 않는다.
- 공유 직전 최종 미리보기를 반드시 제공한다.

## 11. SNS 공유 범위

### MVP 포함

- 공유 카드 PNG 생성
- 이미지 다운로드
- 공유 문구 클립보드 복사
- 지원 환경에서 운영체제 기본 공유 메뉴 호출
- 공유 미지원 환경의 대체 안내

### MVP 제외

- Instagram, Threads, X 계정 로그인
- 각 SNS 계정에 직접 자동 게시
- 게시물 성과 분석
- 공개 커뮤니티 피드

## 12. 로컬 데이터 정책

- 기본 저장소: localStorage
- 이미지 원본이나 음성 파일은 저장하지 않는다.
- 사진 ID, 이미지 URL, 사진가 정보, 대화 요약, 선택 문장, 작은 행동, 편집 설정만 저장한다.
- 원문 전체 저장 여부는 사용자가 선택한다.
- `기록하지 않고 이용하기`를 제공한다.
- 전체 삭제 기능을 쉽게 찾을 수 있게 한다.
- localStorage가 암호화 저장소가 아니며 공용 기기에서 노출될 수 있음을 알린다.

## 13. Unsplash 사용 원칙

- API가 반환한 이미지 URL을 사용한다.
- 앱에서 사진가와 Unsplash 출처 및 링크를 제공한다.
- 카드 저장 등 다운로드에 해당하는 동작에서 `download_location`을 호출한다.
- Access Key와 Secret Key를 저장소에 커밋하지 않는다.
- `.env.local`은 Git에서 제외하고 `.env.example`만 제공한다.
- 사진 속 식별 가능한 사람, 브랜드, 작품이 공유 카드에 포함될 수 있음을 안내한다.

## 14. MVP 범위

### 반드시 포함

- 모바일 우선 반응형 UI
- 감정 선택
- Unsplash 사진 검색·선택
- 텍스트 입력
- Push-to-Talk 음성 입력
- 규칙 기반 안내 질문 표시
- 안내 질문 음성 재생
- 3~7분의 단계별 자기성찰 흐름
- 작은 행동 선택
- 마음 기록 localStorage 저장·삭제
- 마음 카드 편집·PNG 저장
- 기본 공유 메뉴와 문구 복사
- 위기 도움 화면

### 이후 단계

- 계정과 클라우드 동기화
- 대화 기록 암호화
- SNS 직접 게시
- 감정 변화 통계
- 철도 노선·역 기반 테마 확장
- 전문가용 콘텐츠 관리 화면
- 다국어 지원
- 네이티브 앱

## 15. MVP 성공 기준

정식 임상 효과가 아니라 사용성과 안전성을 기준으로 검증한다.

- 신규 사용자가 설명 없이 첫 기록을 완료할 수 있다.
- 평균 7분 이내에 사진 선택부터 결과 확인까지 완료할 수 있다.
- 텍스트와 음성 입력을 대화 중 전환할 수 있다.
- 음성 인식 결과를 전송 전에 수정할 수 있다.
- 사용자가 전체 대화를 공개하지 않고 문장 하나만 카드로 만들 수 있다.
- 모바일에서 카드 PNG 저장 또는 공유가 가능하다.
- 저장된 모든 기록을 사용자가 직접 삭제할 수 있다.
- 위기 문구 테스트에서 일반 대화 대신 도움 화면이 노출된다.
- Unsplash 출처와 다운로드 추적 요건을 충족한다.

## 16. 핵심 비기능 요구사항

- 모바일 화면 폭 360px부터 정상 사용 가능
- 주요 버튼과 텍스트는 키보드로 접근 가능
- 이미지 위 텍스트는 충분한 명암 대비 확보
- 마이크 권한 거부 시 텍스트 모드로 자연스럽게 전환
- Unsplash 또는 브라우저 음성 기능 오류 시 재시도와 대체 메시지 제공
- API 키와 사용자 기록을 Git 저장소에 포함하지 않음
- 사용자 동의 없이 마이크를 활성화하지 않음
- 페이지 새로고침 후에도 저장된 기록 유지

|---|---|
| 대상 | 일상적인 감정을 정리하려는 성인 |
| 포지셔닝 | 비의료 자기성찰·웰니스 도구 |
| 대화 입력 | 텍스트와 Push-to-Talk 음성 |
| 안내 음성 출력 | 브라우저 음성합성 선택 기능, 기본 꺼짐 |
| 기록 | 로컬 저장, 저장하지 않기 지원 |
| 공유 | 사용자가 선택한 문장만 포함 |
| 배포 | 로컬 실행 우선, 이후 GitHub Pages 검토 |
| 직접 SNS 게시 | MVP 제외 |
| 사용자 계정 | 없음 |

## 18. 개발 전 남은 결정

기술명세서 작성 단계에서 다음을 확정한다.

1. 브라우저 음성 인식의 지원 범위와 대체 UX
2. 공개 배포 시 Unsplash API 프록시 또는 샘플 데이터 방식
3. 마음 카드의 최종 시각 디자인 시스템
4. 위기 감지 규칙의 전문가 검토 절차

## 19. 출시 단계

### 1단계: 로컬 프로토타입

- 샘플 사진과 규칙 기반 대화로 전체 흐름 검증
- 카드 이미지 생성과 localStorage 검증

### 2단계: Unsplash 연결 MVP

- Unsplash 검색 연결
- 음성 입력·출력 연결
- 안전 흐름 테스트

### 3단계: 공개 데모

- 비밀 키를 보호하는 프록시 구성

- 모바일 공유 호환성 점검

### 4단계: 전문가 검토 및 개선
